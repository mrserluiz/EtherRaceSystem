# EtherRaceSystem V0.1

Plugin de raças do servidor EtherCraft para Paper (Java 21).

## Raças iniciais
- Humano: 1.0 (32 px)
- Elfo: 1.09375 (35 px)
- Fada: 0.78125 (25 px)
- Anão: 0.90625 (29 px)
- Draconato: 1.0 (32 px)
- Tiefling: 1.0 (32 px)

## Condições sobrenaturais
- Lobisomem: obtido com Dente de Lobisomem
- Vampiro: obtido com Presas de Vampiro

Essas condições são adicionais à raça base.

## Compilação
Execute `mvn package` com Java 21. O JAR será produzido em `target/` quando as dependências forem resolvidas.

## Observação
Versão inicial para testes em Paper, inclusive com clientes Bedrock via Geyser. Ainda não homologada em servidor.
